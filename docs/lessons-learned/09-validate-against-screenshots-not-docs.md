# Lesson: Validate Against Screenshots, Not Against What the Docs Say Should Happen

BeyondTrust's documentation is generally good, but UI behavior can lag or diverge from
what's written, especially across appliance versions. When something doesn't match,
trust the screenshot in front of you and go looking for why, rather than assuming user
error.

**Takeaway:** treat a mismatch between the docs and the live UI as a signal to
investigate the version difference, not as evidence you did something wrong.

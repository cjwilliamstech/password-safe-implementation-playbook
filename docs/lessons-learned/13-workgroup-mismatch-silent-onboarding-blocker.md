# Lesson: Workgroup Mismatch Is a Silent Onboarding Blocker

If a functional account is registered with Workgroup = "None" (or any value that
doesn't match the Managed System's workgroup), it simply won't appear in that system's
functional account dropdown — no error, it just isn't in the list.

**Takeaway:** default to the standard/default workgroup used across your managed
systems unless you have a specific reason to segment further.
